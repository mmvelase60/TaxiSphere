# Contributing to TaxiSphere

TaxiSphere is organized like an enterprise engineering project. Contributions should be traceable, reviewed, and aligned with the project documentation.

## Contribution Rules

- Keep changes focused and easy to review.
- Link significant work to a requirement, ADR, issue, or documented project goal.
- Update documentation when behavior, architecture, or workflow changes.
- Do not introduce new frameworks or major dependencies without an ADR.
- Prefer simple, maintainable solutions over clever abstractions.

## Branch Naming

```text
feature/short-description
bugfix/short-description
hotfix/short-description
docs/short-description
release/v1.0.0
```

## Pull Request Checklist

- The change has a clear purpose.
- Documentation has been updated where needed.
- Tests or verification steps are included where practical.
- Security and tenant isolation impacts have been considered.
- The change follows the existing project structure.

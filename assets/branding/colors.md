# TaxiSphere Color Palette

## Core Colors

| Token | Hex | Usage |
| --- | --- | --- |
| `ts-blue-700` | `#1F4D78` | Deep headings, trusted enterprise tone |
| `ts-blue-600` | `#2E74B5` | Primary brand actions and document headings |
| `ts-green-600` | `#168A5B` | Success, mobility, operational health |
| `ts-orange-500` | `#F28C28` | Movement, warnings, dispatch urgency |
| `ts-gray-900` | `#212529` | Primary text |
| `ts-gray-600` | `#5A6169` | Secondary text |
| `ts-gray-100` | `#F2F4F7` | Tables, section backgrounds, subtle surfaces |
| `ts-white` | `#FFFFFF` | Page and card backgrounds |

## Usage Guidance

- Use blue for brand identity, headings, and primary navigation.
- Use green for positive operational status.
- Use orange sparingly for attention and dispatch urgency.
- Use gray for structure and neutral UI states.
- Keep formal documents restrained and readable.

# TaxiSphere Typography

## Font System

| Context | Font |
| --- | --- |
| Formal documents | Aptos or Calibri |
| Web application | Inter |
| Code and technical snippets | JetBrains Mono or Consolas |
| Diagrams | Inter or Aptos |

## Document Type Scale

| Role | Size |
| --- | --- |
| Document title | 24-30 pt |
| Heading 1 | 16 pt |
| Heading 2 | 13 pt |
| Heading 3 | 12 pt |
| Body text | 11 pt |
| Table text | 9.5-10 pt |
| Footer text | 9 pt |

## Guidance

- Prioritize readability over visual decoration.
- Keep heading hierarchy consistent.
- Use bold for emphasis, not entire paragraphs.
- Use code font only for commands, filenames, identifiers, and snippets.
